  THE TWO INTERFACES YOU IMPLEMENT FOR YOUR OWN COMPONENTS

  interface A2uiComponent {
      val name: String
      val description: String
      val properties: List<A2uiProperty<*>>
      fun isReady(scope, properties): Boolean          // default
      fun Content(scope, properties, modifier)         // @Composable
  }

  interface A2uiCatalog {
      val id: String                                   // the catalogId on the wire
      val components: A2uiComponentCollection
      val functions:  A2uiFunctionCollection
      val themeSchema: A2uiSchema
      fun isInline(): Boolean                          // default
  }

  Nothing here mentions Material. material3-a2ui is just one
  implementation of A2uiCatalog -- you can register your own design
  system the same way, and pass several catalogs to one processor.
